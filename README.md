# まなびの 王国

**ぴっちキッズラボ** の 子ども向け 学習アプリです。

けいさんプリンセスと 同じ 王国の 4つの 場所で、考える 力・かん字・作文・手ちょうを そだてる アプリ（統合版）。

- 考える 森（ルゥ）：なぜ？カード・言ばの はしご
- 図書かん（ノア）：かん字 3回てん・だめおし
- ゆうびんきょく（ペン）：作文・せつ明文・読書かんそう文
- 時計とう（チクタ）：子ども手ちょう・週の まとめ・手紙

## しくみ
- src/places/<場所>/ … もとの 4つの アプリを そのまま 入れたもの。セーブの キーも そのまま
- CSS は tools/scope-css.mjs で .pl-<場所> の 中だけに きくように して いる（npm run dev / build で 自動）
- src/kingdom.js … 王国の スタンプカード（どこかで 1つ やった 日）、手ちょうの 自動で きえる やる こと、まるごと バックアップ、保護者アプリ むけ レポートコード（QR）
- けいさんプリンセスへの リンクは src/App.jsx の KEISAN_URL（本番の URL に かえる）

## うごかす
```bash
npm install
npm run dev
npm run build
npm run build:single
```
